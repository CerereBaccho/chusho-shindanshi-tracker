# 失敗パターン DB（lessons-learned）

このファイルはセッション中に発生したエラーや問題を記録し、再発防止策を蓄積するためのファイルです。

## 運用ルール

- エラーが発生し解決したら、その日中に追記する
- 毎週末の作業開始前30分で棚卸しする
- 同じパターンが2週以上続いた場合、`%USERPROFILE%\.claude\CLAUDE.md` のルールへ昇格させる
- 再発しなくなったものには `[解決済み]` ラベルを付けてアーカイブする

## 記載フォーマット

```text
## [YYYY-MM-DD] エラーの概要タイトル

- **状況**: どのような操作をしていたか
- **エラー内容**: 表示されたエラーや問題の詳細
- **原因**: 判明した根本原因
- **対処**: 実際に解決した手順
- **再発防止策**: ルール化・Skill 化すべき点
- **ステータス**: 調査中 / 解決済み
```
