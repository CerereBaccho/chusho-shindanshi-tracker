# 用語集

本ファイルはプロジェクト固有の用語、略語、固有名詞の定義を集約します。初出時に揺れが生じないよう、表記を統一します。

## 表記ルール

- 略語は初出時に正式名称を併記する
- 英数字と日本語の間には半角スペースを入れる（例: `localStorage の設定`）
- 製品名、サービス名は公式表記に従う

## 用語一覧

### A〜Z

#### dayIdx

- 正式名称: day index
- 説明: 学習開始日からの経過日数（0始まり）。`PHASES` 配列のどのフェーズに属するかを特定するキー
- 関連: `getPhase(dayIdx)`、`daysSince()`

#### localStorage

- 正式名称: Web Storage API（localStorage）
- 説明: ブラウザに永続保存される Key-Value ストア。本アプリのすべての学習データはここに保存される
- キー設計: `day:YYYYMMDD`（日別データ）、`start-date`（学習開始日）、`notif-time`・`notif-enabled`（通知設定）
- 関連: `store` オブジェクト

#### SPA

- 正式名称: Single Page Application
- 説明: ページ遷移なしにタブ切替でビューを差し替えるアーキテクチャ。本アプリは単一 HTML ファイルで実現している
- 関連: `switchTab()`、`.page.active`

### 日本語用語

#### 週末モード

- 説明: 土曜・日曜に `weekendTasks`（週末用追加タスク）をバナーとして表示する機能
- 関連: `isWeekend()`、`phase.weekendTasks`、`.weekend-banner`

#### 中小企業診断士

- 説明: 経済産業省が管轄する国家資格。1次試験（7科目筆記）と2次試験（事例記述4問）で構成される
- 本アプリの学習計画: 2026年4月〜2028年10月の約2年間・11フェーズ

#### フェーズ

- 説明: 科目単位の学習期間。`PHASES` 配列の1要素に対応。`start`〜`end`（dayIdx）で期間を定義する
- フェーズ数: 11（財務・会計×2、企業経営理論、運営管理、経済学・経済政策、4科目総復習、経営情報システム、経営法務、中小企業経営・政策、全科目総復習、2次試験対策）
- 関連: `PHASES`、`getPhase()`

#### 連続学習日数（ストリーク）

- 説明: 今日から連続して学習記録がある日数。`minutes > 0` または `done.length > 0` またはマニュアルタスク完了がある日を「学習した日」とカウントする
- 関連: `computeTotals()`、`#streak`

#### 目標学習時間

- 説明: 2次試験合格に必要とされる目安の累計学習時間。本アプリでは 1000 時間を固定値として設定している
- 関連: `#remaining`（`1000 - 累計時間` を表示）
